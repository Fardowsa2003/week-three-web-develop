
# Budget Tracker - Week 3

## Project Description

Budget Tracker is a simple and user-friendly web application designed to help users organize and monitor their daily expenses.

## Project Author

FARDOWZA ALI HASSAN

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Project Files

### index.html
Contains the structure of the Budget Tracker application, including the expense form, expense table, logo, and other page sections.

### style.css
Controls the visual design of the application.

It includes:
- Consistent color palette
- Google Fonts typography
- Styled expense table
- Styled form inputs and buttons
- CSS Box Model
- Margins and padding
- Borders and rounded corners
- Hover effects
- Responsive design

### README.md
Provides information about the project and explains the purpose of each file.

## Design Features

- Professional blue and white color palette
- Poppins headings
- DM Sans body typography
- Modern card-based layout
- Alternating table row colors
- Rounded buttons and input fields
- Responsive mobile layout

## How to Run

1. Open the project folder.
2. Open index.html in your browser.
3. View the Budget Tracker application.
